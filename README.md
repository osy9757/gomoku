# 오목 (Gomoku)

온라인 2인용 오목 게임. 렌주룰, 방 코드 매칭, 채팅, 엑셀 테마 지원.

## 실행

```bash
npm install
npm start          # http://localhost:3000 (PORT 환경변수로 변경 가능)
```

다른 PC에서 접속하려면 같은 네트워크에서 `http://<이 PC의 IP>:3000` 으로 접속하세요.

## Docker로 실행

```bash
docker compose up -d          # 빌드 + 실행 (http://localhost:9757)
PORT=8080 docker compose up -d  # 다른 포트로
docker compose logs -f        # 로그
docker compose down           # 중지
```

기본 호스트 포트는 9757입니다 (배포 서버의 빈 포트 기준). PORT 환경변수로 변경할 수 있습니다.

서버(리눅스)에서도 Docker+Compose만 있으면 동일하게 동작합니다.

## 기능

| 기능 | 설명 |
|------|------|
| 로컬 2인 | 한 화면에서 번갈아 착수 (기본 모드) |
| 렌주룰 | 흑에게 3-3, 4-4, 장목(6목+) 금수 적용. 금수 지점은 빨간 ✕로 표시. 5목 완성은 금수보다 우선. 자유룰로 전환 가능 |
| 온라인 대전 | "방 만들기"로 6자리 코드 생성 → 상대가 "코드로 참가". 방장이 흑돌. 서버가 턴/금수를 검증. 재대국 시 색상 교대 |
| 채팅 | 온라인 대전 중 우측 채팅 패널 (Enter로 전송) |
| 엑셀 테마 | 우측 상단 🎨 버튼. 수식 줄 `=OMOK(...)`, A~O/1~15 헤더, 시트 탭 등 스프레드시트 화면으로 변신 |
| 게임 종류 | 오목 · 오델로 · 사목 · 포커(2~6인 세븐포커) · 인디언포커(2~6인). 모두 로컬/온라인 지원 |
| 포커(2~6인, 2인 = 맞포커) | 2명이면 그대로 1:1 맞포커가 된다. 온라인은 최대 6인 좌석제 테이블 방 — 방장이 "게임 시작", 좌석별로 자기 카드만 내려받는다. 로컬은 인원(2~6)을 고른 뒤 차례마다 가리개가 뜨는 핫시트. 앤티 10, 4장 중 1장 매장·1장 오픈, 4번의 베팅 라운드(체크/삥/콜/하프/따당/다이), 올인은 사이드 팟으로 층별 정산 |
| 인디언포커(2~6인) | 1~10 두 벌(20장)에서 각자 **한 장**. **남의 카드는 다 보이지만 내 카드만 못 본다**(포커와 정반대 마스킹). 앤티 10 → 베팅 한 라운드(포커와 동일한 금액 산식) → 높은 숫자가 승. 다이로 끝나면 카드를 공개하지 않아 승자도 자기 카드를 끝내 모른다. **10을 들고 다이하면 벌금 10**이 팟에 더해진다. 포커와 같은 테이블 방/핫시트 구조 |
| 기타 | 무르기(온라인에선 상대 동의 필요), 기보, 플레이어별 타이머, 승리 돌 강조 |

## 구조

- `server.js` — Express 정적 서빙 + WebSocket(`/ws`) 방/채팅/대국 중계 (서버 권위 상태 관리)
- `public/rules.js` — 순수 규칙 로직 (승리 판정, 렌주 금수). 브라우저/서버 공용
- `public/cards.js` · `public/sevenpoker.js` — 카드/족보 판정과 세븐포커(2~6인) 결정적 상태 기계. 브라우저/서버 공용
- `public/indianpoker.js` — 인디언포커(2~6인) 결정적 상태 기계. 칩·팟·베팅 규칙은 `sevenpoker.js` 가 내보내는 `betting` 헬퍼를 그대로 공유하고, 카드 규칙(1장·역마스킹·10 벌칙)만 따로 구현
- `public/game.js` — 클라이언트 UI·네트워크 로직
- `public/style.css` — 기본(우드) 테마 + `body.theme-excel` 엑셀 테마
- `test-rules.js`, `test-ws.js` — 규칙/프로토콜 검증 스크립트 (`node test-rules.js`)
